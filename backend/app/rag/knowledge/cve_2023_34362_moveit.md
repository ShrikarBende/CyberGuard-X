# CVE-2023-34362
CVE-2023-34362 is a SQL injection vulnerability in Progress MOVEit Transfer that has been associated with exploitation. Investigation should verify whether MOVEit Transfer is deployed, determine the product version and patch state, review vendor-recommended indicators and logs, and inspect unusual access or data transfer associated with the server. This CVE is relevant only when asset and telemetry evidence supports applicability.

# Evidence and response
Preserve application, authentication, web, and network logs. Validate suspicious access with the service owner and vendor advisory. Containment, patching, credential rotation, or service shutdown requires authorized human approval.
